Interactive diagram of C++ template metaprogramming: primary template fallback with partial specialization, and SFINAE as a compile-time guard

Layer 1 — the inspector
primary template
template<typename T> struct Trait { ... };
default fallback — used when nothing more specific matches
partial specialization
template<> struct Trait<int> { ... };
compiler prefers the most specific match it finds

Layer 2 — the security guard (SFINAE)
template<typename T, typename = std::enable_if_t<has_toString<T>::value>> void process(T val) { val.toString(); }
Substitution Failure Is Not An Error: if the type fails the check, the compiler quietly removes this overload from candidates instead of erroring — as if it were never written.
